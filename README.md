# jiejuefuyou.github.io

The AutoApp portfolio site — landing page + PromptVault Web edition.

Hosted via GitHub Pages at https://jiejuefuyou.github.io.

## Files

- `index.html` — landing page (4 apps + toolkit + writing links)
- `prompts.html` — PromptVault web edition (113 prompts, embedded JSON, `{{variable}}` substitution, one-click copy)
- `_config.yml` — Jekyll config (only used by Pages, harmless otherwise)

## Privacy

This site collects nothing. No analytics, no cookies, no third-party JavaScript. The PromptVault web edition runs 100% client-side — your variable inputs never leave your browser.
